The `piloop` package has one subpackage for each concern, and imports point down its layers.
[CONTRIBUTING.md](https://github.com/hiloopai/piloop/blob/main/CONTRIBUTING.md#package-layout) lists the layers and the
rules.

The graph below is generated from the import statements in `piloop/`. An arrow points from the importer to what it
imports. An arrow that a longer path already implies is left out, so the layers show. The table after the graph has
every direct import.
